# How to Use Silver Labels Without Data Leakage

## 🚫 The Current Problem (Data Contamination)

```
Your current approach:
┌─────────────────────────────────────────────┐
│  Step 1: Generate labels with v5.0          │
│  Step 2: Test v5.0 on those same labels     │
│  Result: 98-100% accuracy (inflated!)       │
└─────────────────────────────────────────────┘

This is like giving a student the answer key,
then testing them on the same questions.
```

---

## ✅ Solutions: Leakage-Free Evaluation

### **Solution 1: Cross-Prompt Validation** ⭐ RECOMMENDED

Generate labels with some prompts, test with different prompts.

```
Generators: v2.0, v3.0, v6.0 (ensemble of 3 prompts)
                           ↓
Creates robust silver standard
                           ↓
Test All: v1.0, v2.0, v3.0, v4.0, v5.0, v6.0
          (none tested against themselves)
```

**Why this works:**
- v5.0 is tested against labels from v2, v3, v6 (not itself)
- No prompt sees its own output during testing
- Still uses AI-generated labels (no human labeling needed)

**Expected accuracy:**
- Theme F1: ~70-80% (realistic estimate)
- Sentiment Acc: ~70-85% (realistic estimate)
- Risk Acc: ~80-90% (realistic estimate)

**How to implement:**
```bash
# Step 1: Generate cross-validation labels
python generate_crossval_labels.py --prompts v2 v3 v6 --samples 175

# Step 2: Evaluate all prompts fairly
python evaluate_crossval.py

# Results: Fair, unbiased estimates for all prompts
```

---

### **Solution 2: Ensemble Silver Standard**

Generate labels with multiple prompts, use majority vote.

```
For each review:
  v2.0 labels → sentiment: 2, themes: [A, B]
  v3.0 labels → sentiment: 2, themes: [A, C]
  v6.0 labels → sentiment: 3, themes: [A, B]
                    ↓
  Ensemble → sentiment: 2 (majority vote)
            themes: [A, B, C] (union)
```

**Why this works:**
- Ensemble label is more robust than any single prompt
- Reduces bias from any one prompt
- Still fully automated

**Trade-off:**
- More expensive (3x API calls per review)
- Slightly more complex

---

### **Solution 3: Leave-One-Out Cross-Validation**

For each prompt, generate labels with all OTHER prompts.

```
Test v1.0 → Labels from v2.0, v3.0, v4.0, v5.0, v6.0
Test v2.0 → Labels from v1.0, v3.0, v4.0, v5.0, v6.0
Test v3.0 → Labels from v1.0, v2.0, v4.0, v5.0, v6.0
...and so on
```

**Why this works:**
- Every prompt gets a fair test
- No prompt tested against itself
- Most rigorous approach

**Trade-off:**
- Most expensive (6x generation cost)
- More complex implementation

---

### **Solution 4: Human-Labeled Gold Standard** 💰 EXPENSIVE

Have humans label 50-100 reviews.

```
Human experts label 100 reviews
           ↓
Gold standard (ground truth)
           ↓
Test all prompts against human labels
```

**Why this works:**
- True ground truth
- No bias from AI labels
- Most accurate evaluation

**Trade-off:**
- Expensive (time + money)
- Time-consuming
- Requires domain expertise
- Inter-annotator agreement issues
